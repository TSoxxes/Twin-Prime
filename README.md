A research codebase for exploring prime number distributions using a geometric-computational architecture, inspired by methods such as the Goldston-Pintz-Yıldırım (GPY) sieve.

This project provides tools to:
- Generate "prime vectors" (sparse representations of primes).
- Calculate conceptual sieve weights.
- Perform analyses related to prime k-tuples.

The long-term goal is to develop a framework for computational experiments in number theory, particularly concerning conjectures about prime gaps.

## Overview

The Prime Vector Space (PVS) library implements core functionalities for representing primes and applying sieve-theoretic concepts. It is designed for researchers and enthusiasts in computational number theory.

The initial implementation is based on the specifications from:
- "A Geometric-Computational Architecture for Resolving the Twin Prime Conjecture"
- "Revised Prime Vector Space Plan"

## Features

- **Prime Sieve:** Efficient Sieve of Eratosthenes (`sieve_of_eratosthenes`).
- **Prime Vector Construction:** Sparse matrix representation of primes up to `n` (`build_prime_vector`), handling up to `n=1e8` (with stubs for larger `n`).
- **GPY Weights (Conceptual):** Placeholder for Goldston-Pintz-Yıldırım style sieve weights (`gpy_weight`).
- **CLI Tool (`pvs`):**
    - `generate`: Create prime vectors and save as Parquet files.
    - `analyse`: Perform conceptual analysis on prime vectors, compute placeholder statistics, and optionally plot results.
- **Testing:** Unit tests with `pytest`, aiming for high coverage (>=90%).
- **CI/CD:** GitHub Actions for automated linting, testing across multiple Python versions and OS.
- **Dependency Management:** Managed with Poetry.

## Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/prime-vector-space.git
    # Replace your-username/prime-vector-space with the actual repository URL
    cd prime-vector-space
    ```

2.  **Install dependencies using Poetry:**
    ```bash
    poetry install
    ```
    This installs all core and development dependencies.

3.  **For visualization features (optional):**
    ```bash
    poetry install --extras viz
    ```
    This installs `matplotlib` for plotting capabilities in the `analyse` command and notebooks.

## Quickstart

1.  **Activate the Poetry environment:**
    ```bash
    poetry shell
    ```

2.  **Generate a prime vector:**
    Create a prime vector for numbers up to `n = 1,000,000` and save it.
    ```bash
    pvs generate --max-n 1000000
    ```
    Output will be saved to `data/processed/prime_vector_1000000.parquet`.

3.  **Analyze the prime vector:**
    Run a conceptual analysis on the generated file.
    ```bash
    pvs analyse --input-file data/processed/prime_vector_1000000.parquet
    ```
    To include plots (if `viz` extras are installed):
    ```bash
    pvs analyse --input-file data/processed/prime_vector_1000000.parquet --plot
    ```

4.  **Run tests:**
    ```bash
    pytest
    ```
    To include coverage report:
    ```bash
    pytest --cov=pvs
    ```

## Command-Line Interface (CLI)

The `pvs` command provides access to the library's functionalities.

-   **`pvs generate --max-n <N> [--output-dir <path>] [--filename <name>]`**
    -   `--max-n <N>`: (Required) Generate primes up to this integer.
    -   `--output-dir <path>`: Directory to save the Parquet file. Defaults to `./data/processed/`.
    -   `--filename <name>`: Custom name for the output Parquet file. Defaults to `prime_vector_<N>.parquet`.

-   **`pvs analyse --input-file <path> [--k <int>] [--u-factor <float>] [--plot|--no-plot]`**
    -   `--input-file <path>`: (Required) Path to the Parquet file generated by the `generate` command.
    -   `--k <int>`: Parameter `k` for GPY weights (default: 2).
    -   `--u-factor <float>`: Factor to determine `u` for GPY weights (default: 0.5, where `u = u-factor * log(max_n_from_file)`).
    -   `--plot` / `--no-plot`: Enable/disable plotting (default: disabled). Requires `matplotlib`.

For more details on commands and options:
```bash
pvs --help
pvs generate --help
pvs analyse --help
```
